How it was built

Five experiments

Compared on validation; test read once

The data

Daily sales from Corporación Favorita (Kaggle): 54 stores, 4.5 years, 8 perishable families, 727,488 rows.

What was hiding in it

Fake zeros, Christmas Day missing, a pre-Christmas spike, the 2016 earthquake, and paydays, each turned into a cleaning rule or feature.

Honest evaluation

Split by date, leak-free features proven by tests, a fair baseline first, test weeks read once.
