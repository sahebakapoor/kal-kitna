DVC + MLflow
The surprise: the 28-day lag helped only with the faster learning rate. An isolating run revealed the interaction.

The data

Daily sales from Corporación Favorita (Kaggle): 54 stores, 4.5 years. Kal Kitna keeps the 8 families that spoil fast: 727,488 rows.

What was hiding in it

Fake zeros before each product's first sale, Christmas Day missing, a pre-Christmas spike, the April 2016 earthquake, and paydays. Each became a cleaning rule or a feature.

Honest evaluation

Split by date, every feature built only from earlier days (proven by tests), a fair baseline first, and the test weeks read once.

One command rebuilds everything: uv run dvc repro
